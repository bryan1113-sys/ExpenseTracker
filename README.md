# Expense Tracker

A simple java console application for tracking expenses and calculating total spending.

## Features
- Add an expense with a description and amount
- Store multiple expenses
- Display all expenses
- Calculate total spending

## Technologies Used

- Java
- IntelliJ IDEA
- Git
- GitHub

## What I Learned

This project helped me practice Java fundamentals, including classes, objects, ArrayLists, loops, user input, and basic Git version control.
